# RoleMI

RoleMI 是一个面向求职者的浏览器侧边栏插件，帮助用户在看到职位后，判断它真正需要什么样的人、自己是否适合，以及接下来应该怎么投。

界面保留 RoleMI 原始图标，以蓝色为主、青色和紫色为少量点缀；卡片弱化阴影与装饰，保持轻松、清爽和低信息压力。空岗位欢迎卡在右侧放大裁切原品牌图标作为低透明度水印，并用蓝、青、紫三个柔光节点对应看懂岗位、看清差距和知道怎么投。

按钮颜色只表达操作语义：蓝色实心用于页面当前的主要动作，蓝色描边用于查看、取消、测试和重新执行等次级动作，蓝色文字用于低优先级跳转；红色描边用于清除、清空等危险入口，真正执行删除的确认按钮使用红色实心。禁用状态统一降灰，加载时保持原按钮层级并锁定重复提交。

关键异步操作在处理中会锁定按钮并在成功或失败后恢复；服务设置的测试、保存与恢复默认互斥执行，岗位分析会拦截同一内容的重复请求。岗位卡片通过独立详情按钮覆盖整卡点击区域，避免与星标、分析按钮形成嵌套交互控件；简历上传入口保留键盘操作能力。

复制岗位描述和沟通草稿时，界面以浏览器实际复制结果为准；复制权限被拒绝时会提示用户手动复制，不显示虚假成功状态。

一句话定位：**先看懂岗位，再决定怎么投。**

## 面向用户

适合需要快速筛选机会，以及正在转行、跨行业或跨职能求职的人。

自动提取支持 BOSS 直聘、智联招聘和猎聘。官网、公众号、猎头消息等其他渠道的职位描述，可以手动粘贴最多 2000 字。

推荐使用流程：

```text
收集职位 ─→ 理解岗位要求 ─┐
                          ├─→ 分析匹配 ─→ 优化简历 / 生成开场白
上传简历 ─→ 理解个人经历 ─┘
```

使用时不需要关心内部处理顺序：上传简历后，RoleMI 会先整理其中的工作、项目、技能和成果；解析失败或提取文本超过 4000 字时会在页面保留明确提示。点击“开始分析”时，系统会自动完成岗位分析并给出结论。同一份简历可以连续分析多个岗位。

## 三个核心价值

### 看懂岗位

不只提取关键词，而是先理解岗位本质、核心要求、隐含要求，以及公司真正想找什么样的人。

### 看清差距

不提供缺少依据的匹配百分比，而是区分直接匹配、可迁移能力和真正的关键缺口，帮助用户判断自己为什么适合或不适合。

### 知道怎么投

从简历修改到沟通开场白，围绕当前岗位给出下一步行动建议，帮助用户判断值不值得投，以及应该怎么投。

## 如何使用

### 安装与启动

当前版本用于本地联调：

1. 在 Chrome / Edge 扩展管理页开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，加载本项目目录。
3. 启动配套后端，然后打开 RoleMI 侧边栏。

插件默认连接 RoleMI 服务，无需填写模型或密钥；也可以在设置中连接自己的 Responses API。

### 使用流程

1. **收集职位**：在 BOSS 直聘、智联招聘或猎聘的职位详情页点击“提取当前岗位”；其他来源可使用“手动添加岗位”。
2. **上传简历**：选择自己的 PDF 或 DOCX 简历，等待内容整理完成。
3. **分析匹配**：进入“匹配”页，点击“开始分析”。上传简历后不会自动开始匹配。
4. **准备投递**：查看匹配结论与简历修改建议，或生成求职开场白。

岗位池为空时，首页显示独立欢迎页：以浅蓝卡片询问“今天在看什么机会？”，下方提供整行“提取当前岗位”、文字型“手动添加岗位”、支持平台说明，以及“看懂岗位、看清差距、知道怎么投”三项能力提示；不展示岗位列表工具和批量操作。添加岗位后切换回管理视图，岗位总数显示在搜索框右侧，并恢复岗位池批量操作。

手动添加岗位时只需填写最多 2000 字的岗位描述；职位名称、公司 / 地点、经验 / 学历和薪资默认收起，可按需展开补充。岗位描述为空时不能提交。

右上角菜单提供使用帮助、反馈建议和服务设置。服务设置会标明当前使用默认或自定义服务，并可一键清除自定义地址、模型和会话 API Key，恢复 RoleMI 默认服务。使用帮助按四类功能在当前页面独立抽拉，允许同时展开多个条目，无需逐项进入详情页。空岗位首页不选中“岗位池”标签；岗位池和收藏页均可点击整张岗位卡片打开岗位详情，星标固定在卡片右上角并与标题行对齐，底部“分析岗位 / 查看分析”使用带边框的独立按钮。收藏页提供“导出收藏”；清空岗位池使用页面内确认框，并明确简历不会删除。所有子页面左上角统一显示“返回”。简历匹配区左侧显示文件名，右侧固定显示“上传 / 更换简历”；该入口与“重新分析”使用完全相同的紧凑次级按钮规格。处理或异常状态才补充状态文字。

## 数据说明

岗位、简历与分析结果保存在浏览器本地。使用托管服务时，完成分析所需的内容会临时发送给模型服务；匿名使用统计不包含简历、JD 或分析正文。
