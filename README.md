# JDGET

JDGET 是一个 Manifest V3 浏览器扩展，用于从招聘网站页面提取 JD 信息，并将结果保存到本地 Excel 文件。

当前版本重点适配 BOSS 直聘搜索列表页的右侧职位详情结构，同时保留 JSON-LD 和通用 DOM 兜底能力。

## 核心能力

- 一键提取当前页面正在查看的 JD。
- 将多条 JD 记录暂存在浏览器本地。
- 导出 `.xlsx` 文件到本地。
- 支持 BOSS 直聘薪资遮盖数字还原，例如 `-K` 可导出为类似 `25-30K`。
- 支持导出完整页面 HTML 和 DOM 结构报告，方便后续按真实页面结构调试。

## 导出字段

Excel 使用中文表头，当前导出字段如下：

- 岗位名称
- 公司名称
- 工作地点
- 工作经验
- 学历要求
- 薪资
- JD原文
- 发布日期
- 来源链接

## BOSS 直聘适配说明

BOSS 直聘搜索结果页并不是传统职位详情页，而是“左侧职位列表 + 右侧动态详情”的页面结构。JDGET 当前按实际页面 DOM 结构提取：

- 详情容器：`.job-detail-container .job-detail-box`
- 岗位名称：`.job-detail-header .job-detail-info .job-name`
- 薪资：`.job-detail-header .job-detail-info .job-salary`
- 工作地点、工作经验、学历要求：`.job-detail-header .tag-list li`
- JD 原文：`.job-detail-body > p.desc`
- 公司名称：通过右侧详情中的 jobId 匹配左侧职位卡片，再读取 `.job-card-footer .boss-name`

这样可以避免把 HR 信息、工作地址、热门职位、推荐内容等页面噪声写入 JD 原文。

## 安装调试

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录：`JDGET`。
5. 打开招聘页面，点击浏览器工具栏中的 JDGET。

## 使用方式

1. 在招聘网站中打开目标职位页面，或在 BOSS 直聘搜索列表中选中右侧职位详情。
2. 点击插件中的“提取当前 JD”。
3. 继续浏览其他职位，并重复提取。
4. 点击“导出 Excel”，保存 `.xlsx` 文件。
5. 如果需要重新开始一批数据，点击“清空”删除本地记录。

## DOM 调试

如果字段提取不准确，可以点击“导出DOM结构”下载当前页面的 DOM 报告。

报告包含：

- `fullHtml`：完整页面 HTML
- `fullHtmlLength`：HTML 字符长度
- 当前提取结果
- 字段候选节点
- 可读 DOM 轮廓

该功能用于确认真实页面结构，并为后续新增网站适配或修复字段提取问题提供依据。

## 版本迭代

### v0.1.0

- 初始化 Manifest V3 浏览器扩展。
- 实现插件弹窗、当前页面提取、本地存储和 Excel 导出。
- 内置无依赖 `.xlsx` 生成逻辑。
- 增加 DOM 结构导出调试能力。

### v0.2.0

- 增加 BOSS 直聘页面适配。
- 支持薪资遮盖数字还原。
- 将 Excel 表头调整为中文。
- 根据实际页面 HTML，改为按 `.job-detail-box` 结构提取右侧职位详情。
- 公司名称改为通过详情 jobId 匹配左侧职位卡片提取。
- 删除无用导出列，仅保留当前需要的岗位字段。
- 清理历史兜底代码，简化内容脚本结构。
