# RoleMI

RoleMI 是一个求职辅助浏览器插件：先看懂岗位，再决定怎么投。

## 能做什么

- 从 BOSS 直聘、智联招聘和猎聘提取岗位；智联支持搜索、推荐和职位分类入口，也支持手动粘贴岗位描述。
- 分析岗位本质、核心要求、隐含要求和理想候选人。
- 结合 PDF / DOCX 简历，区分直接匹配、可迁移能力和关键缺口。
- 根据真实经历生成简历修改建议和求职开场白。
- 收藏、搜索并导出岗位。

## 本地运行

1. 启动配套后端。当前插件默认连接 `http://localhost:8787`。
2. 在 Chrome 或 Edge 的扩展管理页开启开发者模式。
3. 选择“加载已解压的扩展程序”，加载本项目目录。
4. 打开 RoleMI 侧边栏。

默认使用 RoleMI 服务，也可以在服务设置中连接自己的 Responses API。

## 使用流程

1. 提取或手动添加岗位。
2. 查看岗位分析。
3. 上传简历；上传后不会自动开始匹配，需要手动点击分析。
4. 查看修改建议或生成沟通草稿。

岗位描述手动录入上限为 2000 字；简历支持 PDF 和 DOCX，提取文本上限为 4000 字。

网页提取会等待岗位标题和岗位描述都可用；页面仍在加载、安全验证、登录失效或岗位已下线时不会保存不完整岗位，并会提示对应处理方式。

## 数据与隐私

岗位、简历和分析结果保存在浏览器本地。使用 AI 功能时，完成分析所需的内容会临时发送给模型服务。匿名使用统计不包含简历、岗位描述或分析正文。
