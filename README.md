# JDGET

JDGET 是一个 Manifest V3 浏览器扩展，用于从招聘网站详情页提取 JD 信息，并导出为本地 Excel 文件。

## 当前功能

- 从当前招聘详情页提取岗位名称、公司名称、工作地点、工作经验、JD 内容和学历要求。
- 对部分招聘站点的遮盖数字做还原，例如 `-K·薪` 会导出为类似 `20-40K·14薪`。
- 优先读取页面里的 `JobPosting` JSON-LD 结构化数据。
- 对 BOSS 直聘页面优先按 HTML 结构提取职位、薪资、详情正文和公司信息，减少顾问信息、推荐职位等噪声混入。
- 对没有结构化数据的网站，使用常见 DOM 选择器和关键词兜底提取，并尽量截取“职位描述”到“工作地址”之间的正文。
- 导出 Excel 使用中文表头：岗位名称、公司名称、工作地点、工作经验、学历要求、薪资、JD原文、发布日期、来源链接。
- 将多次提取结果保存在浏览器本地存储。
- 导出 `.xlsx` 文件到本地下载目录。

## 安装调试

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目目录：`JDGET`。
5. 打开招聘详情页，点击浏览器工具栏里的 JDGET。

## 使用方式

1. 在招聘网站的职位详情页点击“提取当前 JD”。
2. 继续浏览其他职位详情页并重复提取。
3. 点击“导出 Excel”，选择保存位置。

## DOM 调试

如果字段提取不准确，点击“导出DOM结构”可以下载当前页面的 DOM 结构报告。报告包含完整页面 HTML（`fullHtml`）、页面 URL、当前提取结果、字段候选节点、重要容器和可读 DOM 轮廓，用于按真实 HTML 结构调整解析器。
