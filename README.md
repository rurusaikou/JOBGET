# JOBGET

JOBGET 是一个面向求职者的浏览器侧边栏插件，帮助用户在看到职位后，判断它真正需要什么样的人、自己是否适合，以及接下来应该怎么投。

一句话定位：**先看懂岗位，再决定怎么投。**

## 面向用户

适合需要快速筛选机会，以及正在转行、跨行业或跨职能求职的人。

自动提取支持 BOSS 直聘、智联招聘和猎聘。官网、公众号、猎头消息等其他渠道的职位描述，可以手动粘贴最多 1000 字。

推荐使用流程：

```text
收集职位 ─→ 理解岗位要求 ─┐
                          ├─→ 分析匹配 ─→ 优化简历 / 生成开场白
上传简历 ─→ 理解个人经历 ─┘
```

使用时不需要关心内部处理顺序：上传简历后，JOBGET 会先整理其中的工作、项目、技能和成果；点击“开始分析”时，系统会自动完成岗位分析并给出结论。同一份简历可以连续分析多个岗位。

## 三个核心价值

### 看懂岗位

不只提取关键词，而是先理解岗位本质、核心要求、隐含要求，以及公司真正想找什么样的人。

### 看清差距

不提供缺少依据的匹配百分比，而是区分直接匹配、可迁移能力和真正的关键缺口，帮助用户判断自己为什么适合或不适合。

### 知道怎么投

从简历修改到沟通开场白，围绕当前岗位给出下一步行动建议，帮助用户判断值不值得投，以及应该怎么投。

## 如何使用

### 安装与启动

当前版本用于本地联调：

1. 在 Chrome / Edge 扩展管理页开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，加载本项目目录。
3. 启动配套后端，然后打开 JOBGET 侧边栏。

插件默认连接 JOBGET 服务，无需填写模型或密钥；也可以在设置中连接自己的 Responses API。

### 使用流程

1. **收集职位**：在 BOSS 直聘、智联招聘或猎聘的职位详情页提取 JD；其他来源可使用“手动添加JD”。
2. **上传简历**：选择自己的 PDF 或 DOCX 简历，等待内容整理完成。
3. **分析匹配**：进入“匹配”页，点击“开始分析”。上传简历后不会自动开始匹配。
4. **准备投递**：查看匹配结论与简历修改建议，或生成求职开场白。

右上角菜单提供使用帮助、反馈建议和 API 设置。使用帮助按四类功能进入详细操作说明；提交反馈时可选择本地岗位池中的相关岗位；选择后会附带该岗位 JD 与已生成的工作流结果快照，用于定位问题和分析 Bad Case，但不会提交简历原文或附件。

## 数据说明

岗位、简历与分析结果保存在浏览器本地。使用托管服务时，完成分析所需的内容会临时发送给模型服务；匿名使用统计不包含简历、JD 或分析正文。
