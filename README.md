# JOBGET

JOBGET 是一个面向求职者的浏览器侧边栏插件，用于从招聘网站提取 JD，整理岗位池，收藏重点岗位，并导出本地 Excel 文件。

当前项目基于 Chrome Manifest V3 实现，已支持 BOSS 直聘、智联招聘和猎聘的职位详情页。

## 面向用户

JOBGET 面向正在主动找工作、需要批量收集和比较岗位信息的求职者，尤其适合需要整理多个 JD、收藏重点机会、后续做简历匹配和投递沟通的人。

## 主要功能

已实现：

- JD 提取
- JD 收藏
- JD 导出
- API 配置
- JD 智能分析
- PDF / DOCX 简历本地结构化
- 简历与 JD 匹配分析结构化输出
- 简历修改建议独立展示
- 基于匹配亮点生成求职开场白

需要优化：

- 简历解析模块当前仍处于验证阶段，需要提升不同简历版式的稳定性
- 简历匹配分析和简历修改建议结构已达要求，但模型输出字数偏多，需要继续压缩 prompt 和展示策略

待办：

- 简历多版本和模板化导出
- 简历编辑和 PDF 导出新方案

详细功能设计、项目架构和模型选型在本地 `docs/` 目录维护，不随 GitHub 仓库发布。

## 安装方法

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录：`JDGET`。
5. 打开招聘页面，点击浏览器工具栏中的 JOBGET，插件会在浏览器侧边栏打开。

## 使用方法

1. 打开支持的招聘网站职位详情页。
2. 点击侧边栏中的“提取当前JD”。
3. 在岗位池中查看、搜索和收藏 JD。
4. 在“API 设置”中配置 OpenAI 或兼容 OpenAI 协议的服务。
5. 点击岗位池中的“深度分析”，生成岗位本质、核心要求、隐形要求和理想候选人。
6. 在“匹配”中上传 PDF / DOCX 简历，生成本地 Resume JSON。
7. 点击“导出全部JD”导出岗位池数据，包含基础 JD、深度分析、匹配结论和简历修改建议。
8. 进入“收藏”页，点击“Excel导出”导出收藏岗位，字段与全部导出保持一致。
9. 如需重新开始，点击“清空岗位池”删除本地记录。

深度分析说明：

- 初次点击会基于当前 JD 调用模型分析。
- 已有分析结果时再次进入不会重复调用模型。
- 点击结果页中的“重新分析”会重新发起模型请求。
- JD 内容为空、超过 10000 字或内容异常时不会发起分析。
- API 调用失败时会展示失败状态，并支持重新分析。
- API 设置中只长期保存服务商、Base URL 和模型名；API Key 仅保存到当前浏览器会话，关闭浏览器后需要重新输入。

简历上传说明：

- 当前只支持 PDF / DOCX。
- PDF 使用本地内置 PDF.js 读取文本层，不支持扫描版 PDF。
- DOCX 使用本地内置 Mammoth.js 读取纯文本。
- 当前只保留纯文本结构，不解析头像、图片或原始版式。
- 结构化过程在本地完成，不调用模型。
- 当前可上传、替换和清除简历；旧版结构化简历编辑器已移除。
- 简历与 JD 匹配度、证据、修改建议和求职开场白会调用用户配置的模型服务，输入包含当前 JD、JD 分析结果、PDF / DOCX 提取出的简历完整原文，以及 Resume JSON 辅助结构化结果。
- 简历修改建议已移动到“修改建议”标签页，匹配页只展示匹配结论、证据和缺口。
- 当前简历匹配分析和修改建议的模块结构已满足要求，但输出内容偏长，需要继续收敛。

当前支持的网站：

- BOSS 直聘
- 智联招聘
- 猎聘

## 版本迭代

### v0.4.0

- 将 JOBGET 原型界面迁入真实扩展侧边栏。
- 岗位池接入现有 JD 提取、本地存储、去重和 Excel 导出能力。
- 新增收藏、详情、深度分析、匹配、简历修改建议、沟通草稿和 API 设置视图。
- 深度分析接入 OpenAI-compatible API，支持结构化输出、结果复用、失败重试和异常 JD 拦截。
- 接入 PDF / DOCX 简历解析、简历与 JD 匹配分析、简历修改建议和求职开场白生成。
- 当前简历模块体验未达最终要求；开场白模块已基于匹配亮点接入模型生成。

### v0.3.0

- 新增智联招聘职位详情页适配。
- 新增猎聘职位详情页适配。
- 新增来源网站导出列。
- 统一发布日期和薪资清洗。
- 增加异常页面兜底，非支持网站或非 JD 详情页不保存记录。

### v0.2.0

- 支持通过浏览器侧边栏常驻使用，切换页面时不需要重新打开插件。
- 支持提取保存和导出 Excel 时自动去重。

### v0.1.0

- 初始化 Manifest V3 浏览器扩展。
- 实现插件面板、当前页面提取、本地存储和 Excel 导出。
- 内置无依赖 `.xlsx` 生成逻辑。
