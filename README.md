# JDGET

JDGET 是一个 Manifest V3 浏览器扩展，用于从招聘网站页面提取 JD 信息，并将结果保存到本地 Excel 文件。

当前版本支持 BOSS 直聘、智联招聘和猎聘的职位详情页。

## 核心能力

- 一键提取当前页面正在查看的 JD。
- 将多条 JD 记录暂存在浏览器本地。
- 导出 `.xlsx` 文件到本地，并在保存和导出时自动去重。
- 支持固定到浏览器侧边栏，切换页面时 JDGET 保持打开。
- 支持薪资清洗，包括 BOSS 直聘遮盖数字还原和 `面议`。
- 异常页面会提示原因，不保存无效记录。

## 导出字段

Excel 使用中文表头，当前导出字段如下：

- 岗位
- 公司
- 工作地点
- 工作经验
- 学历要求
- 薪资
- JD原文
- 发布日期
- 来源网站
- 来源链接

## 安装调试

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录：`JDGET`。
5. 打开招聘页面，点击浏览器工具栏中的 JDGET，插件会在浏览器侧边栏打开。

## 使用方式

1. 在招聘网站中打开目标职位页面，或在 BOSS 直聘搜索列表中选中右侧职位详情。
2. 点击插件中的“提取当前 JD”。
3. 继续浏览其他职位，并重复提取。
4. 点击“导出 Excel”，保存 `.xlsx` 文件。
5. 如果需要重新开始一批数据，点击“清空”删除本地记录。

重复 JD 会按来源链接、岗位名称、公司名称、地点和薪资识别；重复提取时不会再次写入本地列表，导出 Excel 前也会再次去重。
